What is it?

A restrained Apple-inspired watch for your desktop: one glass card, a large local time display, and a progress ring that doubles as a live complication. Click the ring to cycle modes, right-click to pick the ring color with the native macOS eyedropper.

Install

One command, no git needed. You need macOS and Übersicht (free).

$curl -fsSL https://raw.githubusercontent.com/rijan-poudel/apple-clock-Widget/main/install.sh | sh

Then click the Übersicht icon in the menu bar → Refresh, and enable clacky if it isn't on already.

Ring modes

  • Battery — battery level, shows charging when plugged in
  • Second — live seconds and progress through the minute
  • Year — day of the year and progress through it
  • Weekend — hours until Saturday
  • Color — pick the ring color

Clicking & permissions

For the ring to respond to clicks, give Übersicht Accessibility access (System Settings → Privacy & Security) and enable its Interaction Shortcut in Übersicht's preferences.

Automatic updates

Installed via the command above, Clacky pulls the latest version from GitHub whenever Übersicht loads it (at most once per hour). Your position, mode, and color are never overwritten.

Customize

Open index.jsx in the widget folder and edit the config object to change 12/24-hour display, accent color, which modes are enabled, the default mode, or to turn off auto-updates (autoUpdate: false).
