OVERVIEW

What is it

One glass face on your desktop: the local time, and a ring that doubles as a live gauge — it's ticking above, in real time, right now. Click the ring to switch what it's tracking. Right-click to pick its color with the system eyedropper.

INSTALL

Install

One command. No git required. Needs macOS and Übersicht (free).

$curl -fsSL https://raw.githubusercontent.com/rijan-poudel/apple-clock-Widget/main/install.sh | sh

Open the Übersicht menu-bar icon → Refresh, then switch clacky on if it isn't already.

Prefer no terminal?

  1. Download the ZIP
  2. Unzip it, rename the folder to clacky.widget
  3. In Übersicht's menu bar, choose Open Widgets Folder and drop it in
  4. Refresh from the menu-bar icon

Manual installs stay put — no automatic updates.

PERMISSIONS

Clicks & permissions

Give Übersicht Accessibility access (System Settings → Privacy & Security), then turn on its Interaction Shortcut in Übersicht's own preferences. That's what lets the ring respond to clicks.

Right-click the ring to open the native macOS eyedropper and pick the ring color — no extra permissions needed, it uses the system color sampler.

UPDATES

Automatic updates

Installed with the command above, Clacky checks GitHub for a newer build every time Übersicht loads it — at most once an hour. Your position, mode, and color always survive the update.

CONFIGURE

Customize

Open index.jsx inside the widget folder. The config object at the top controls the clock format (12 or 24-hour), the accent color, which modes are on, the default mode, and autoUpdate: false if you'd rather manage updates yourself.
